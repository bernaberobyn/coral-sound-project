# coral-sound-project

## Overview
In this project, we have used sounds collected from the environment around coral reefs and used it to build a 
model that classifies whether a coral reef is healthy, degraded or restored.

## Dataset Specification
The dataset consisted of a total of 262 audio files, out of which 81 were healthy, 71 were degraded and 110 were restored. The dataset for the project can be found [here](https://www.kaggle.com/datasets/maryrobynbernabe/coral-sound-dataset).
